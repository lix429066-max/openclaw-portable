Cache tool results to avoid redundant reads. Best for: multi-step workflows where the same file is read multiple times. Use get to check cache before reading a file that was recently read. Cache entries expire after 30 seconds.

When to use:
- Multi-step workflows where the same file is read multiple times
- Before re-reading a file you just read within the last 30 seconds
- When context budget is tight and you want to avoid re-reading

When NOT to use:
- Files that change frequently (cache may be stale)
- First-time reads (cache misses waste a tool call)
- Files larger than 200K chars (truncation may lose data)

Actions:
  get   — read from cache (returns hit: true/false)
  set   — save to cache (key + value required)
  clear — wipe entire cache

Note: cache is in-memory only, cleared on gateway restart.
